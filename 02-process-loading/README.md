# 寻知 · AI 对话过程演示

这是一个可离线打开的单页 HTML 原型，用来演示 AI 任务的过程状态、失败回复与人工重试。页面不连接模型或真实服务，也不执行实际工具操作；界面事件均为模拟数据。

当前原型保持为静态单页，打开即可演示。后续正式实现按 Vue 3、TypeScript 与 Tailwind CSS 技术栈交付。

## 在线与本地预览

[打开 GitHub Pages 演示](https://rayklein-prog.github.io/ai-conversation-process-demo/)。GitHub Actions 发布 `public-release/`。

本地可直接打开 [ai-conversation.html](ai-conversation.html)，也可使用 [index.html](index.html) 预览。页面所需 Logo 在 `assets/brand/`，没有 Figma 运行时请求或外部网络依赖。

## 演示内容

原型包含常规过程、复杂成功过程和失败状态预览。失败预览可选择以下六类原因：

| 原因 | 自动重试 | 最终提示 |
| --- | --- | --- |
| 网络连接失败 | 最多 5 次连接尝试 | 检查网络后重试 |
| 请求超时 | 最多 5 次请求尝试 | 稍后重试；持续发生时可简化任务 |
| 服务暂时不可用 | 最多 5 次请求尝试 | 稍后重试 |
| 请求频率受限 | 不自动重试 | 等待一段时间后手动重试 |
| 可用额度不足 | 不自动重试 | 补充额度后手动重试 |
| 登录状态或权限失效 | 不自动重试 | 重新登录或确认权限后手动重试 |

所有最终失败都显示通用说明、具体原因卡片和同一个“重试”按钮。按钮会重跑当前演示场景；若失败原因未解决，模拟结果仍会失败。

## 交互规则摘要

- 连续网络、超时及服务故障只显示一条连接状态，按 1/5 到 5/5 更新；不逐条列出重试记录，也不展示代码或原始请求 JSON。
- 自动重试达到上限后停止，收起过程历史，并在正文显示失败原因卡片。用户可以展开历史回看状态。
- 已知不可由短暂等待恢复的频率、额度和权限错误不进行自动重试，直接给出原因。
- 若真实服务在自动重试上限前恢复，应继续同一轮任务并隐藏临时连接状态；此成功恢复路径目前只记录在规则中，原型重点演示最终失败。
- 失败卡片使用灰色背景和红色错误图标，标题 16px、中等字重；空间充足时重试按钮位于右侧，窄屏时移到说明下方。
- 对话框右上方的 IP 形象与名称已移除。过程状态的图标与文字保持分离并使用中性色。

完整状态、错误分类、重连节奏、布局、滚动和真实事件接入要求见 [过程加载与交互规则.md](过程加载与交互规则.md)。原型背景与设计记录见 [AI-CONVERSATION-README.md](AI-CONVERSATION-README.md)。
